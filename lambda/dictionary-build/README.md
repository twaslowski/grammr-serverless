# dictionary-build

Builds the dictionary artifact that `lambda/dictionary` serves.

This is offline tooling, not a deployed function — the same arrangement as
`lambda/preprocessing`: it lives under `lambda/` because it belongs to that
service, but it has no Terraform module and is never packaged.

## Data source

[wiktextract](https://github.com/tatuylonen/wiktextract) extractions of the
**English** edition of Wiktionary, published at
[kaikki.org](https://kaikki.org/dictionary/rawdata.html) and refreshed every few
days.

The English edition rather than the per-language ones, because it carries
entries for every target language *with English glosses* — which is what a
learner whose source language is English or German needs. It is also the only
single source that supplies all four things an entry needs at once: senses, part
of speech, inherent features such as noun gender, and a parsed inflection table.

Scraping Wiktionary directly is not an option worth considering: inflection
tables are generated by Lua modules, so getting at them means reimplementing
template expansion, which is the hard part wiktextract already solved.

## Usage

```sh
# Against the published dump. 2.6 GB gzipped, streamed and filtered by language,
# so nothing bigger than one JSON line is ever in memory.
uv run python build.py ru

# Against a local copy, which is what you want while iterating on the mapping.
uv run python build.py ru --source ~/dumps/raw-wiktextract-data.jsonl.gz --out dist/ru.sqlite
```

Then publish it. The bucket policy in `terraform/shared/s3.tf` grants Lambda read
on `dictionary/*`:

```sh
aws s3 cp dist/ru.sqlite "s3://${AWS_ACCOUNT_ID}-eu-central-1-grammr/dictionary/ru.sqlite"
```

The Lambda reads whatever is at that key on its next cold start. Nothing needs
redeploying, but in-flight containers keep the copy already in `/tmp`, so a
refresh propagates as those age out.

Refresh cadence is manual. Wiktionary moves slowly enough that quarterly is
ample, and a scheduled rebuild would mean an unreviewed dataset change landing in
production.

## Verifying an artifact before publishing it

```sh
API_GW_URL=... API_GW_API_KEY=... uv run python verify.py dist/ru.sqlite
```

This is the confidence gate, and it is the step worth not skipping. Two sources
now claim to know Russian morphology — Wiktionary via `build.py`, and pymorphy3
behind `POST /inflections/ru` — and where they disagree, one of them is wrong.
`verify.py` compares them cell by cell and groups the disagreements by
coordinate, so each *class* of difference can be looked at once rather than
sampled by hand.

Each class is one of three things: a bug in the tag mapping, a real divergence
between the sources, or coverage the dictionary adds that pymorphy3 declines.
The report separates the last one out (`cells the service does not produce`,
`service declined`) precisely because it is the point of the exercise rather than
a defect.

Deliberately not a pass/fail threshold. "Under 2% disagree" is not the bar; the
bar is having understood every class above the noise. Forms are matched after
normalisation, so stress marking and `ё` spelling never register as
disagreements — both sources are inconsistent about those and neither
inconsistency is interesting.

Sampling is by `sense_count` descending, as a stand-in for frequency. It is a
proxy and not a good one; a real frequency list is the honest fix and would also
give search-result ranking something better to sort on.

## Tests

```sh
uv run --frozen pytest
```

`fixtures/ru-sample.jsonl` is a committed slice of real dump lines, chosen to
cover the cases that actually break: a noun with inherent gender, an adjective
whose gender is *inflectional* instead, an imperfective verb where present and
compound-future forms compete for the same cell, an adverb with no paradigm, an
indeclinable noun, a gloss-less form-of stub, a homograph pair, and an entry in
another language.

## Adding a language

1. Write `tag_mapping/<code>.py`, following `ru.py`. The tag vocabulary
   Wiktionary uses is language-specific, and this is the only part that is.
2. Register it in `MAPPERS` and add the Wiktionary language name to
   `LANGUAGE_NAMES` in `build.py`.
3. Extend `fixtures/` with real dump lines for that language and mirror the test
   classes in `test_build.py`.

The values a mapper emits are not free choices. `InflectionsTable` in
`src/components/inflection/inflections-table.tsx` looks cells up by exact value
(`{CASE: "NOM", NUMBER: "SING"}`), and `src/lib/feature-labels.ts` translates
those values for display, so they have to match the enum member names in
`lambda/inflections-ru/inflections/domain/feature.py`. One inherited quirk to
know about: grammr calls the instrumental `ABL` and the prepositional `LOC`.
